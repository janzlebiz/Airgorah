# 01 — Feature Inventory & Traceability Matrix

## 1. Complete Feature Inventory

Every feature present in `martin-olivier/airgorah` is cataloged below and mapped to its **Airgorah Mobile** Android implementation, status, and verification requirement.

| # | Original Feature | Upstream Location | Android Implementation | Status | Verification |
|---|---|---|---|---|---|
| 1 | **Wi-Fi Discovery (APs)** | `agent/backend/sniffer.rs`, `scan.rs` | Native Android `WifiManager.startScan()` / `ScanResult` + `WifiManager.ScanResultsCallback` (API 30+), enriched with Rust OUI vendor lookup | Planned | Required |
| 2 | **Client Discovery** | `agent/backend/sniffer.rs` (`record_probe`, `record_data_client`) | Authorized inventory from imported PCAP frames (via Rust `libwifi`/`radiotap` parser) and local network/ARP/NSD metadata where permitted; clear distinction between observed vs inferred data | Planned | Required |
| 3 | **Monitor Mode** | `agent/backend/interface.rs` (`iw`, `ip`) | Hardware Capability Abstraction Layer (`HardwareCapabilityManager`): inspects built-in Wi-Fi vs USB-OTG adapter descriptors, reports actual Android/driver capability without assuming chipset support | Conditional | Required |
| 4 | **Channel Management** | `common/channel.rs`, `sniffer.rs` (`plan_channel`, `build_channel_list`) | Rust `channel.rs` reused via JNI for 2.4 GHz / 5 GHz channel validation & planning; Android `ScanResult` frequency-to-channel mapping; adapter-scoped channel configuration | Conditional | Required |
| 5 | **MAC Address Management** | `agent/backend/interface.rs` (`macchanger`) | Android privacy/MAC randomization status display (`WifiInfo` / `ScanResult` limitations); no root `macchanger` shelling | Unsupported (Hardware/OS) / Informational | Required |
| 6 | **Deauthentication Module** | `agent/backend/deauth.rs`, `gui/frontend/interfaces/deauth.rs` | Preserved as **Deauthentication Lab** (defensive detection & educational simulation): simulated topology, simulated client devices, simulated deauth events, event timeline, PMF/802.11w defense guidance, report generation. **No operational frame transmission.** | Planned | Required |
| 7 | **Handshake Capture & Detection** | `common/handshake.rs`, `agent/backend/capture.rs` | Rust `handshake.rs` via JNI for PCAP/CAP import, EAPOL M1–M4 classification, completeness validation (`M2 && (M1 || M3)`), integrity status (`Valid`, `Invalid`, `Incomplete`, `Unsupported`, `Failed`). **No credential recovery.** | Conditional / Planned | Required |
| 8 | **PMKID Detection & Analysis** | `common/handshake.rs` (`has_crackable_pmkid`), `agent/backend/pmkid.rs` | Rust `handshake.rs` via JNI for RSN PMKID KDE extraction, key descriptor version inspection (WPA2 vs WPA3-SAE), artifact classification, and defensive findings. **No active solicitation/cracking.** | Planned | Required |
| 9 | **Password Testing / Decryption** | `gui/backend/decrypt.rs`, `gui/frontend/interfaces/decrypt.rs` | Preserved as **Password Audit** (defensive password strength assessment): length, character classes, common-pattern detection, entropy estimation with documented limitations, policy recommendations, local test scenarios. **No dictionary/brute-force cracking, no external transmission, no plaintext storage.** | Planned | Required |
| 10 | **Vendor (OUI) Resolution** | `agent/backend/vendors.rs`, `vendors.csv` | Reused directly in Rust `airgorah-core` via JNI (`find_vendor`) for offline MAC-to-manufacturer lookup | Planned | Required |
| 11 | **PCAP Capture Management** | `agent/backend/pcap.rs`, `capture.rs` | Android Storage Access Framework (SAF) PCAP/CAP import, Rust `PcapReader` metadata & packet statistics, integrity validation, export, delete, and Room persistence | Planned | Required |
| 12 | **Reports** | `gui/backend/report.rs` (JSON) | Native Report Generator supporting **PDF**, **JSON**, and **CSV** across 7 report types, distinguishing observed, imported, simulated, and inferred data | Planned | Required |
| 13 | **Settings & Preferences** | `gui/backend/settings.rs` (`config.toml`) | Jetpack DataStore (`Preferences`) for theme, scan preferences, hidden AP display, simulation defaults, and privacy controls | Planned | Required |
| 14 | **Hardware / Interface Picker** | `gui/backend/iface.rs` (`/sys/class/net`) | Android `WifiManager` + `UsbManager` (USB-OTG) + `ConnectivityManager` capability matrix (Built-in Wi-Fi, External USB, Unsupported, Simulated) | Planned | Required |
| 15 | **Privilege Escalation (`polkit`)** | `agent/main.rs`, `package/.policy` | Replaced by Android Runtime Permissions (`ACCESS_FINE_LOCATION`, `NEARBY_WIFI_DEVICES`, `ACCESS_WIFI_STATE`, `CHANGE_WIFI_STATE`, `UsbManager.requestPermission`) with user-facing rationale | Replaced | Required |
